# QA Checklist

Ручной проход по реальному устройству. Автотесты покрывают логику, но не
проверяют TTS, уведомления, темы и поведение на железе.

Отмечайте пункты по факту. Каждый провал — отдельная строка в `docs/QA_BUGS.md`
с шагами воспроизведения и версией сборки.

## Первый запуск
- [ ] Онбординг показывается один раз (4 страницы: 3 слайда + выбор уровня).
- [ ] После «Начать» → главный экран.
- [ ] Первый урок открывается и содержит слова выбранного уровня.
- [ ] Перезапуск приложения не показывает онбординг снова.

## Урок
- [ ] Свайп вправо = «знаю», влево = «не знаю».
- [ ] Кнопки «Не знаю» / «Знаю» работают так же, как свайп.
- [ ] TTS произносит слово (Android: голос установлен в системе).
- [ ] Undo (стрелка в AppBar) откатывает последний ответ и XP.
- [ ] Итоги показывают «Верно: N из M» и XP.
- [ ] «Готово» возвращает на главную, дневная цель обновилась.
- [ ] Системный «назад» в середине сессии спрашивает подтверждение.

## Словарь
- [ ] Список 2071 слова прокручивается без заметных рывков.
- [ ] Поиск «apple» находит «apple».
- [ ] Фильтр по CEFR работает.
- [ ] Фильтр по категории работает.
- [ ] Фильтры складываются (уровень + категория).
- [ ] Добавление «test» → слово появляется в списке.
- [ ] Гомонимы: второе «test» с другим переводом → диалог «Добавить как новое».
- [ ] Оба значения видны в списке и различаются частью речи.

## Игры
- [ ] Error Hunter: задание загружается и проходится.
- [ ] Заполни пропуск: 1 задание.
- [ ] Собери слово: 1 слово собирается.
- [ ] Аудио-диктант: слово слышно, ответ проверяется.

## Ежедневное задание
- [ ] Карточка видна на главной.
- [ ] Прогресс растёт после ответов.
- [ ] «Забрать +N XP» начисляет XP и меняется на «✓ Выполнено».
- [ ] Бейдж серии показывает «Серия: 1 день» после первого claim.
- [ ] Второй claim в тот же день недоступен.

## Профиль
- [ ] Export → JSON в диалоге, «Скопировать» кладёт в буфер.
- [ ] Import этого же JSON → «Данные импортированы», прогресс восстановлен.
- [ ] Reset → подтверждение, прогресс очищен, **слова остались**.
- [ ] Смена уровня → новые слова в уроке подбираются по новому уровню.
- [ ] Скорость TTS меняется и слышна.

## Синхронизация (если собрано с ключами Supabase)
- [ ] Вход по email (magic link приходит).
- [ ] Push: «отправлено N».
- [ ] Второе устройство: Pull → прогресс появился.
- [ ] Без ключей: «Синхронизация недоступна» и профиль не падает.

## Тёмная тема
- [ ] Системная тёмная тема применяется.
- [ ] Все экраны читаемы, контраст достаточный (BL-66).

## Офлайн
- [ ] Авиарежим: урок, повторение, прогресс работают.
- [ ] Подсказка → «Не удалось загрузить подсказку», карточка жива.
- [ ] Error Hunter → «Не удалось загрузить задание» с кнопкой «Повторить».

## Напоминания (если включены)
- [ ] Разрешение спрашивается при включении, не на старте.
- [ ] Напоминание приходит в заданное время (±5–15 минут — inexact alarm).
- [ ] После перезагрузки устройства напоминание восстанавливается.
