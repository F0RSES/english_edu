# QA Bugs

Журнал дефектов с ручного прохода по `docs/QA_CHECKLIST.md` на реальном
устройстве или эмуляторе. Автотесты (778) покрывают логику, но не TTS,
уведомления, тёмную тему и поведение на железе — этот файл для них.

## Как заполнять

1. Пройдите `docs/QA_CHECKLIST.md` от начала до конца.
2. На каждый провал — одна строка в таблице ниже.
3. Пишите **фактическое** поведение, а не «не работает»: что нажали, что
   увидели, что ожидали.
4. Скриншот/видео — ссылка или имя файла в `docs/screenshots/`.
5. После исправления статус меняется на `Fixed`, а в конце строки
   добавляется ссылка на тест, который это ловит.

## Поля

| Поле | Значение |
|---|---|
| ID | `QB-001`, `QB-002`, … |
| Область | раздел чек-листа (Lesson, Dictionary, Games, …) |
| Критичность | `blocker` / `major` / `minor` / `cosmetic` |
| Статус | `open` / `in progress` / `fixed` / `wontfix` / `duplicate` |

Критичность: `blocker` — фичу нельзя использовать; `major` — работает, но
результат неверный; `minor` — неудобно, есть обход; `cosmetic` — вид.
