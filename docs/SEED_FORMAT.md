# Seed Format

Формат файла с учебным контентом. Единственный файл пока — `assets/seed/words_v1.json`.

## Схема

Корень — объект.

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| schemaVersion | `int` | да | Версия схемы; поддерживается только `1` |
| sources | `array` | да | Непустой список источников контента |
| words | `array` | да | Непустой список слов |

### source

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| id | `string` | да | Уникальный идентификатор источника; на него ссылаются слова |
| name | `string` | да | Человекочитаемое название |
| license | `string` | да | Лицензия контента, непустая строка |
| url | `string?` | нет | Ссылка на источник, если есть |

### word

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| id | `int` | да | Положительный, уникальный внутри файла |
| term | `string` | да | Английский термин: trimmed и в нижнем регистре |
| translation | `string` | да | Перевод на русский, непустой |
| transcription | `string?` | нет | IPA, обязательно в обрамлении `/…/` |
| partOfSpeech | `string?` | нет | Одно из: article, verb, preposition, conjunction, pronoun, adverb, adjective, noun, interjection, numeral |
| exampleSentence | `string?` | нет | Пример на английском, непустой если указан |
| sourceId | `string` | да | Должен существовать в `sources` |
| frequencyRank | `int?` | нет | Неотрицательный; повторение даёт warning |
| autoTranslated | `bool?` | нет | `true` — машинный перевод, не проходил ревью; даёт warning |

## Что считается ошибкой

- `schemaVersion` не равен 1.
- Пустые `sources` или `words`.
- Дубликат `source.id`, пустые `source.name` / `source.license`.
- `word.id` ≤ 0 или дубликат.
- `word.term` пустой, с пробелами по краям или не в нижнем регистре.
- Пустой `translation`.
- `sourceId`, которого нет в `sources`.
- `frequencyRank` отрицательный или не целое.
- `partOfSpeech` вне списка.
- `transcription` без `/` по краям.
- Пустой `exampleSentence`, если поле указано.

## frequencyRank

`frequencyRank` — informational-поле: оно отражает позицию слова в исходном списке.

- Уникальность имеет смысл только в пространстве `sourceId`, глобальной уникальности нет.
- Пересечение рангов между источниками корректно: `manual-mvp` 1–20 и `ngsl-auto` 1–100 пересекаются по построению, и это не ошибка.
- Валидатор проверяет только тип и неотрицательность, предупреждений о дублях рангов не выдаёт.

## Что считается warning

- Дубликат `term`.
- Дубликат `frequencyRank`.
- `autoTranslated: true` — контент не проходил ревью.

Warning не блокирует приём файла, но попадает в вывод.

## Auto-translated

`autoTranslated: true` означает «машинный перевод, pending review». Валидатор такие слова пропускает (warning, не ошибка). UI может пометить их, но пометка не заменяет ревью: до релиза все такие слова заменяются на проверенные, `sourceId` меняется на верифицированный. Подробности — `docs/LICENSE_CONTENT.md`.

## Storage

- `term` хранится в нижнем регистре и без пробелов по краям; капитализация — задача UI, не данных.
- Валидатор отвергает `term`, который отличается от `term.trim().toLowerCase()`.
- Все прочие строковые поля хранятся как есть, без нормализации.
- Время в seed не хранится; `frequencyRank` — целое число из источника.

## Как добавить слово

1. Убедиться, что нужный `sourceId` есть в `sources`; иначе добавить источник.
2. Дописать объект в `words`: `term` — нижним регистром, `translation` — непустой.
3. `id` — следующий свободный положительный, уникальный.
4. Проверить файл валидатором (ниже) и прогнать `dart test`.

## Как запустить валидатор

```
dart run tools/validate_seed.dart assets/seed/words_v1.json
```

Успех: `OK: 20 words, 1 source, 0 warnings`, код возврата 0.
Ошибка: строки `ERROR: …` в stderr, код возврата 1.

Логика проверки живёт в `tools/validate_seed_lib.dart` (чистая функция `validateSeed`), CLI — тонкая обёртка.

## Лицензии

`manual-mvp` — **placeholder**: ручная выборка слов, переводы ждут ревью.
При расширении до 300–500 слов источник заменить на реальный: NGSL (CC BY-SA), Oxford 3000 (CC BY) или public domain. Для каждого слова `sourceId` должен указывать на источник с явной лицензией.

## Аудио

TTS подключается в Phase 2 (`stts`, ADR-018). В seed аудио не хранится: ни путей к файлам, ни base64.
